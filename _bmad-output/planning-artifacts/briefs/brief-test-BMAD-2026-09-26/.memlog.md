- (note by user) Vision: Web app automating PFE internship discovery and applications in France and Tunisia
- (note by user) Target: 5th-year engineering students (e.g. ArcTIC), platforms: LinkedIn, Jobteaser, Moovijob, Welcome to the Jungle
- (note by user) Stakes: Personal tool for Jan 2027 PFE search + engineering portfolio showcase, future multi-student potential
- (direction by user) Working mode: Coaching path selected
- (decision by user) Human-in-the-loop: mandatory human review and approval before sending each application (no fully unattended bot)
- (decision by user) Features: Dynamic CV tailoring, ATS alignment scoring, bespoke cover letter with natural student tone (no AI boilerplate), Kanban tracking
- (decision by user) MVP scope: France + Tunisia, LinkedIn + Jobteaser first; automated follow-ups deferred to v2
- (decision by user) Master Profile: Student inputs exhaustive profile (experiences, academic/personal projects, stack, summer internships, strengths); AI strictly draws from this source of truth without hallucinating skills
- (decision by user) Application handling: Easy Apply automated prefill + 1-click submit; External redirects provide 1-click package (PDF CV, copied cover letter, direct link) and max field autofill assistance
- (decision by user) Success criteria: 1) Time per application < 3min vs ~40min, 2) ATS alignment score >= 75-80%, 3) Interview invitation rate >= 15-20% for Jan 2027 PFE
- (decision by user) Vision: Starts as personal high-grade tool and portfolio showcase; evolves into open-source community platform where students can contribute modular scrapers and integrations
- (event by user) Product brief validated and finalized by user
